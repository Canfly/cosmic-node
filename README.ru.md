# CANFLY Cosmic Node

**Открытая экспериментальная платформа для регистрации и исследования космических частиц**

> Первый эксперимент: наземный детектор космических мюонов
> Статус: **ПЛАНИРОВАНИЕ / ЗАКУПКА ОБОРУДОВАНИЯ**
> Целевой срок готовности аппаратуры: **июнь 2027 года**

---

## 1. Идея проекта

**CANFLY Cosmic Node** — открытый экспериментальный проект по созданию небольшого воспроизводимого научного прибора, способного регистрировать частицы, связанные с космическими лучами.

Первый эксперимент намеренно прост:

> **Зарегистрировать космические мюоны на поверхности Земли, записывать отдельные события, исследовать шум детектора и создать пригодный для научного анализа массив данных.**

Проект на первом этапе **не заявляет обнаружение тёмной материи, тёмной энергии или частиц, прилетевших непосредственно от конкретного далёкого астрономического объекта**.

Первая цель гораздо фундаментальнее:

> **Научиться самостоятельно строить, калибровать, эксплуатировать и анализировать настоящий детектор элементарных частиц.**

После успешного освоения этого уровня архитектура может развиваться в направленный мюонный телескоп, сеть наземных детекторов и в дальнейшем — в космический прибор.

---

# 2. Почему мюоны?

Первичные космические лучи постоянно взаимодействуют с ядрами атомов земной атмосферы.

В результате возникают каскады вторичных частиц, содержащие, среди прочего, пионы и каоны. Их распад приводит к образованию мюонов.

Многие мюоны обладают достаточной энергией, чтобы достигать поверхности Земли.

Поэтому мюоны дают относительно простой и практический способ построить экспериментальную связь между лабораторией на Земле и высокоэнергетическими процессами, происходящими в атмосфере и за её пределами.

В документации CAEN для учебных экспериментов приводится характерная энергия мюонов на уровне моря порядка нескольких ГэВ и указывается, что значительная часть мюонов образуется высоко в атмосфере.

### Важное ограничение

Наш детектор **не сможет сказать, что конкретный зарегистрированный мюон прилетел от конкретной звезды или галактики**.

Первый эксперимент измеряет локальный поток вторичных космических мюонов.

Это принципиальное различие необходимо сохранять во всей документации проекта.

* Как она зависит от атмосферного давления?
* Как она зависит от высоты?
* Как она зависит от ориентации детектора?

* Какова скорость случайных совпадений?
* Можно ли восстанавливать направление движения частицы?
* Можно ли обнаруживать коррелированные события несколькими пространственно разнесёнными детекторами?
* Можно ли адаптировать архитектуру для космического эксперимента?

# 4. Чем проект НЕ является

На первом этапе это:

* не детектор тёмной материи;
* не детектор тёмной энергии;
* не гамма-телескоп;
* не нейтринный детектор;
* не астрономический телескоп;
* не система определения источника отдельного космического луча;
* не замена профессиональным космическим обсерваториям.

Проект не должен делать утверждений, которые не подтверждаются измерениями.

Первый успешный результат формулируется значительно проще:

> **Мы зарегистрировали события космических частиц с помощью воспроизводимого прибора и количественно охарактеризовали его работу.**

Для первого экспериментального этапа этого вполне достаточно.

# 5. Принцип работы

Первый детектор состоит из двух независимых сцинтилляционных модулей.

Каждый модуль:

```text
Космическая частица
        ↓
Пластиковый сцинтиллятор
        ↓
Сцинтилляционные фотоны
        ↓
SiPM
        ↓
Предусилитель / схема считывания
        ↓
Дискриминатор
        ↓
Цифровой импульс
```

Два модуля устанавливаются один над другим.

При прохождении частицы через оба детектора возникают примерно:

```text
ВЕРХНИЙ       ─────────●
                       │
                       │ частица
                       │
НИЖНИЙ        ─────────●
```

Электроника ищет два импульса, возникших в пределах заданного временного окна.

Событие считается совпадением, если:

```text
ВЕРХНИЙ = 1
НИЖНИЙ = 1
Δt < заданного окна совпадения
```

Это важно потому, что SiPM сам по себе имеет темновые срабатывания и другие источники электронного шума.

Совпадение двух независимых детекторов позволяет значительно уменьшить вероятность случайного одиночного срабатывания.

CAEN использует именно двухдетекторную coincidence-схему для регистрации космических мюонов и рассматривает её как способ подавления ложных событий и ограничения принимаемого телесного угла.

# 6. Архитектура детектора

Начальная архитектура:

```text
                     КОСМИЧЕСКАЯ ЧАСТИЦА
                              ↓
                    ┌─────────────────┐
                    │ СЦИНТИЛЛЯТОР #1 │
                    │      + SiPM     │
                    └────────┬────────┘
                             │
                       аналоговый сигнал
                             │
                       ┌─────▼─────┐
                       │ READOUT #1│
                       └─────┬─────┘
                             │
                       ДИСКРИМИНАТОР
                             │
                             │
                        ┌────▼────┐
                        │         │
                        │  DAQ    │
                        │         │
                        │  STM32  │
                        │         │
                        └────┬────┘
                             │
                        USB / UART
                             │
                       Raspberry Pi
                             │
                        ХРАНЕНИЕ
                             │
                 ┌───────────┴───────────┐
                 │                       │
              RAW DATA                АНАЛИЗ
```

Второй канал имеет такую же структуру:

```text
СЦИНТИЛЛЯТОР #2
      ↓
     SiPM
      ↓
   READOUT #2
      ↓
 ДИСКРИМИНАТОР
      ↓
    STM32
```

Финальное событие определяется совпадением двух каналов.

# 7. Начальное оборудование

## 7.1 Пластиковые сцинтилляторы

Количество:

**2**

Тип:

**пластиковый сцинтиллятор**

Возможные материалы:

* EJ-200;
* EJ-204;
* аналогичный пластиковый сцинтиллятор.

Начальный ориентир по размеру:

**примерно 50 × 50 × 10 мм**

Точные размеры могут быть изменены после выбора конкретного SiPM и механической конструкции.

Желательно использовать два одинаковых сцинтиллятора.

---

## 7.2 SiPM

Количество:

**2**

Тип:

**Silicon Photomultiplier**

Ориентир:

активная область около 6 × 6 мм.

На первом этапе предпочтительно использовать готовые SiPM-модули или платы считывания, а не проектировать всю схему питания и усиления SiPM самостоятельно.

Цель первого прототипа — сначала получить работающий физический эксперимент, а затем оптимизировать электронику.

---

## 7.3 Платы считывания / предусилители SiPM

Количество:

**2**

Необходимые функции:

* питание SiPM;
* формирование необходимого bias-напряжения;
* снятие сигнала;
* усиление;
* выдача сигнала на осциллограф и дискриминатор.

Конкретная плата выбирается вместе с конкретной моделью SiPM.

Совместимость:

```text
SiPM
+
напряжение смещения
+
предусилитель
+
разъём
+
осциллограф / дискриминатор
```

должна быть проверена до покупки.

---

# 8. Дискриминатор

Необходим:

**двухканальный дискриминатор**

Назначение:

Преобразование аналогового импульса детектора в цифровое событие.

Порог должен быть регулируемым.

Порог не выбирается произвольно: он является параметром эксперимента.

Необходимо исследовать:

```text
Порог
   ↓
Частота одиночных событий
   ↓
Частота совпадений
   ↓
Частота случайных совпадений
```

В учебной аппаратуре CAEN отдельно измеряется темновая частота SiPM в зависимости от порога дискриминатора.

# 9. Система сбора данных

## STM32

Первоначальная платформа:

**STM32**

STM32 отвечает за:

* регистрацию цифровых импульсов;
* измерение времени событий;
* подсчёт одиночных событий;
* регистрацию совпадений;
* формирование записей событий;
* передачу данных компьютеру.

STM32 выбран как предсказуемая платформа для точного тайминга и работы с аппаратными таймерами.

---

## Raspberry Pi

Raspberry Pi выполняет роль длительного регистратора данных.

Функции:

* получение событий от STM32;
* хранение данных;
* локальная база;
* запись экологических параметров;
* мониторинг;
* построение графиков;
* резервное копирование;
* предварительный анализ.

Таким образом:

```text
ДЕТЕКТОР
   ↓
STM32
   ↓ USB/UART
Raspberry Pi
   ↓
БАЗА ДАННЫХ
   ↓
АНАЛИЗ
```

# 11. Экологические датчики

Минимальный вариант:

**BME280 или аналог**

Измеряются:

* температура;
* атмосферное давление;
* влажность.

Атмосферное давление особенно важно, поскольку количество атмосферы над детектором влияет на поток вторичных космических частиц.

Поэтому экологические параметры являются частью научного набора данных, а не просто служебной телеметрией.

---

# 12. Магнитометр

Количество:

**1**

Возможные варианты:

* BMM150;
* LIS3MDL;
* аналогичный трёхосевой магнитометр.

Назначение:

регистрация локального магнитного поля.

На первом этапе магнитометр **не является самостоятельным детектором новой физики**.

Он нужен для записи условий эксперимента и последующего анализа корреляций.

---

# 13. Лабораторное питание

Необходим регулируемый лабораторный источник питания с ограничением тока.

Если подходящий источник уже есть, покупать новый не требуется.

Стабильное питание особенно важно для воспроизводимой работы SiPM.

---

# 14. Осциллограф

Рекомендуемый минимум:

**100 MHz**

Предпочтительно:

**≥1 GS/s**

Осциллограф нужен прежде всего для разработки и калибровки.

С его помощью мы должны увидеть:

* импульсы SiPM;
* сигнал после усилителя;
* базовый шум;
* амплитуду;
* длительность импульса;
* работу дискриминатора;
* электрические помехи;
* временной интервал между каналами.

Он не обязательно будет частью автономного конечного прибора.

---

# 15. Оптический контакт

Необходим:

**оптический гель / optical coupling grease**

Он используется для улучшения оптического контакта между сцинтиллятором и SiPM.

Механическая конструкция должна обеспечивать стабильность этого соединения.

# 16. Кабели и соединения

В зависимости от выбранной электроники понадобятся:

* BNC;
* SMA;
* MCX;
* соответствующие переходники;
* коаксиальные кабели;
* 50-омные терминаторы.

Точный список разъёмов определяется после выбора конкретных электронных модулей.

# 17. Светонепроницаемый корпус

Сцинтиллятор и SiPM должны быть защищены от внешнего света.

Возможная структура:

```text
Сцинтиллятор
      +
SiPM
      ↓
светонепроницаемая оболочка
      ↓
механический корпус
```

Корпус должен обеспечивать:

* полную световую изоляцию;
* механическую стабильность;
* доступ для обслуживания;
* возможность калибровки;
* фиксированную геометрию;
* удобный вывод кабелей.

          │
          │

# 20. Этапы эксперимента

## Этап 0 — Документация

До сборки:

* зафиксировать архитектуру;
* составить BOM;
* записать производителя и артикул каждого компонента;
* зафиксировать параметры SiPM;
* измерить размеры сцинтилляторов;
* описать электрические соединения;
* создать формат данных;
* создать процедуры калибровки.

Каждое научное измерение должно иметь информацию о конфигурации прибора.

---

# 21. Этап 1 — Исследование SiPM

Сначала без сцинтиллятора:

```text
SiPM
 ↓
readout
 ↓
осциллограф
```

Измерить:

* базовый уровень;
* темновую частоту;
* распределение амплитуд;
* зависимость от порога;
* зависимость от температуры.

Это создаёт базовую характеристику электронной части.

---

# 22. Этап 2 — Один детектор

Собрать первый полный модуль.

Измерить:

```text
частота одиночных событий
        ↓
в зависимости от
порога дискриминатора
```

Наша задача — понять работу прибора до включения coincidence.

---

# 23. Этап 3 — Два детектора

Собрать второй модуль.

Сначала измерить отдельно:

```text
R1 = частота детектора №1

R2 = частота детектора №2
```

Затем включить совпадения:

```text
R12 = частота совпадений
```

---

# 24. Этап 4 — Случайные совпадения

Это обязательный этап.

Два детектора могут случайно сработать почти одновременно даже без прохождения одной частицы через оба.

Поэтому необходимо оценить:

```text
R_random
```

и сравнить его с:

```text
R_candidate
```

Случайные совпадения должны быть измерены экспериментально, а не просто проигнорированы.

---

# 25. Этап 5 — Регистрация космических мюонов

Установить два детектора вертикально.

Непрерывно записывать:

```text
частоту канала №1
частоту канала №2
частоту совпадений
температуру
давление
влажность
время
конфигурацию прибора
```

Первая цель:

**24 часа непрерывных данных.**

После успешного прохождения:

**7 суток.**

Затем:

**30 суток.**

# 32. Правила научной работы

### Правило 1

Не называть необъяснимое событие «новой физикой».

Сначала исключить:

* электронный шум;
* темновые импульсы SiPM;
* случайные совпадения;
* шум блока питания;
* электромагнитные помехи;
* температурные эффекты;
* ошибки синхронизации;
* программные ошибки;
* механические изменения;
* влияние окружающей среды.

### Правило 2

Не изменять RAW-данные.

Калибровка создаёт новый слой данных.

### Правило 3

Изменение конфигурации прибора получает новый `configuration_id`.

### Правило 4

Изменение firmware получает новую версию.

### Правило 5

Каждый научный результат должен быть воспроизводим из сохранённых данных.

### Правило 6

Неожиданный результат является поводом для дополнительных измерений, а не для немедленной интерпретации.

# 33. Критерии успеха версии V1

Версия V1 считается успешно реализованной, если система способна:

* работать непрерывно минимум 24 часа;
* регистрировать отдельные события;
* измерять частоту каждого канала;
* регистрировать совпадения;
* количественно оценивать фон случайных совпадений;
* показать статистически значимое превышение физически обусловленных совпадений над измеренным случайным фоном;
* воспроизвести результат в повторном запуске;
* записывать временные и экологические данные;
* сохранять исходные данные;
* повторно построить результаты анализа из сохранённого набора данных.

Для успеха V1 **не требуется обнаружение неизвестного физического явления**.

# 36. Научные ориентиры

Проект опирается на уже существующие экспериментальные методы, а не пытается изобретать принцип регистрации космических мюонов заново.

### CAEN — Muons Detection

Демонстрирует регистрацию космических мюонов с помощью пластикового сцинтиллятора и SiPM.

### CAEN — Muons Vertical Flux

Демонстрирует измерение вертикального потока космических мюонов.

### CAEN — Random Coincidence

Демонстрирует измерение случайных совпадений между детекторами.

### CAEN — Detection Efficiency

Демонстрирует измерение эффективности сцинтилляционных детекторов.

### CAEN — Cosmic Shower Detection

Демонстрирует регистрацию космических ливней несколькими сцинтилляционными детекторами.

### CERN / TIFR

Современные разработки компактных систем регистрации космических лучей используют пластиковые сцинтилляторы, SiPM, дискриминацию и микроконтроллеры STM32.

### CosmicWatch

Открытый образовательный проект компактного детектора космических лучей на основе сцинтиллятора, SiPM и микроконтроллера.

# 37. Философия эксперимента

Проект начинается с маленького вопроса:

> **Можем ли мы построить прибор, который видит частицы, невидимые человеческому глазу?**

Затем:

> **Можем ли мы измерять их достаточно точно?**

Затем:

> **Можем ли мы настолько хорошо понять работу прибора, чтобы доверять полученным данным?**

Затем:

> **Могут ли несколько независимых приборов одновременно зарегистрировать одно и то же физическое явление?**

И только после этого:

> **Что можно узнать о космической среде с помощью такой сети?**

Долгосрочная цель проекта — не устройство, выдающее загадочные числа.

Цель — создать инструмент, данные которого можно:

**проверить → воспроизвести → проанализировать независимо → опубликовать.**
